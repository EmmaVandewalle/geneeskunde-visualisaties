# Geneeskunde Visualisaties

This repository is for visualisations of med concepts. It is not intended to be used to draw conclusions, but rather to help doctors explain concepts more visually.

It is build with Next.js and TypeScript. For styling, it uses Tailwind CSS.

## Installation

```bash
npm install
```

## Running the app

```bash
npm run dev
```
